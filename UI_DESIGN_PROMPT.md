# UI/UX Design Prompt for Stitch (Warehouse Safety Training)

This document contains detailed prompts tailored specifically for generating the UI/UX design of your A-Frame Warehouse Safety Training simulation in **Stitch** (or any AI UI design tool), strictly adhering to your provided nature-inspired, professional color palette.

## 🎨 The Color Palette (Nature-Inspired, Balanced, Professional)
- **Dark Green (`#0A3323`):** Use for main UI panels, dialogue box backgrounds, and footer areas. (Stability, sophistication).
- **Midnight Green (`#105666`):** Use for secondary panels, sidebars, or header backgrounds. (Depth, trust).
- **Moss Green (`#839958`):** Use for primary action buttons, success states, or active indicators. (Balance, calm).
- **Rosy Brown (`#D3968C`):** Use for warning indicators, secondary buttons, or hover states. (Softness, comfort).
- **Beige (`#F7F4D5`):** Use for primary text, typography, icons, and borders. Provides warm, elegant contrast against the dark greens.

---

## 📝 The Prompts

You can copy and paste the following prompts directly into your design tool. 

### 1. Main Prompt (Full HUD & Dialogue Interface)
**Copy this into Stitch:**
> Generate a modern, professional UI HUD (Heads-Up Display) for a web-based 3D warehouse safety training simulation. The design must be nature-inspired and calming, avoiding harsh generic colors. Use this exact color palette: Dark Green (#0A3323) for the main dialogue panel background at the bottom of the screen. The dialogue panel should have a subtle frosted glass (glassmorphism) effect. Inside the panel, use Beige (#F7F4D5) for all text and icons to ensure high readability. Include a speaker name tag that says "Supervisor Dave". Add a "Continue" button using Moss Green (#839958) with Beige text. In the top right corner, include a minimalist task progress tracker (e.g., "Hazards Found: 2/5") with a Midnight Green (#105666) semi-transparent background. The overall aesthetic should be sleek, trustworthy, and highly accessible, floating over a blurred 3D warehouse background. 

### 2. Prompt for Interactive Floating Hotspots
**Copy this into Stitch:**
> Design a floating 2D UI marker/hotspot used to highlight interactive 3D hazards in a warehouse simulation. The marker should feel professional and approachable. Base the design on a circular or diamond shape. Use Rosy Brown (#D3968C) for the outer ring or border to draw attention softly, and fill the center with Dark Green (#0A3323). Place a clean Beige (#F7F4D5) magnifying glass or exclamation icon in the center. Show a small tooltip expanding from the marker with a Midnight Green (#105666) background and Beige text that reads "Inspect Oil Spill". The design should look modern, utilizing subtle drop shadows to lift it off the background.

### 3. Prompt for Multiple Choice Question Menu
**Copy this into Stitch:**
> Design a multiple-choice interaction menu for a 3D safety training simulation. This menu appears when the user needs to answer a supervisor's question. The menu container should be Midnight Green (#105666) with rounded corners and a soft shadow. Inside, display the question text in Beige (#F7F4D5). Below the question, create three selectable option buttons. The default state for the buttons should be Dark Green (#0A3323) with Beige text and a thin Beige border. Show one button in a "hover" or "selected" state using Moss Green (#839958) for the background to indicate a positive, harmonious choice. The typography should be modern sans-serif, clean, and highly legible.

## 💡 Design Tips for Stitch
1. **Glassmorphism:** Mentioning "glassmorphism" or "frosted glass" in Stitch usually yields great results for HUDs that need to float over 3D environments.
2. **Typography:** While the colors are set, prompt Stitch to use modern fonts like *Inter*, *Outfit*, or *Roboto* in Beige (`#F7F4D5`).
3. **Contrast:** The Beige text on Dark Green / Midnight Green backgrounds will easily pass accessibility contrast ratios, making it perfect for industrial training apps.
