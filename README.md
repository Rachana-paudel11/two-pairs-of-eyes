# Two Pairs of Eyes 👁️👁️
> **CET257 Enterprise Project — Team TechNova**  
> *A Desktop Web-Based 3D Workplace Safety Inspection Training Simulation*

---

## 🌟 Overview
**Two Pairs of Eyes** is an interactive 3D browser-based training simulation designed to train warehouse operatives and safety inspectors. The simulation addresses **Risk Normalization** and **Supervisor Authority Bias** by placing the learner alongside a veteran supervisor (**Dave**), challenging the learner to identify workplace hazards, resist unsafe peer pressure, and execute proper health & safety reporting protocols.

---

## 🚀 Quick Start

### 1. Prerequisites
* **Node.js** v18.0.0+ (v20+ LTS recommended)
* Modern browser (Chrome / Edge)

### 2. Setup & Installation
```bash
# Clone the repository
git clone https://github.com/Team-TechNova/two-pairs-of-eyes.git
cd two-pairs-of-eyes

# Install dependencies
npm install
```

### 3. Run Automated Tests
```bash
npm test
```
*Executes all 25 headless unit tests verifying state transitions, scoring, consequences, and scenario schemas.*

### 4. Run the 3D Simulation Locally
```bash
# Using npx serve (recommended)
npx serve . -p 3000
```
Open **`http://localhost:3000`** in your browser.
